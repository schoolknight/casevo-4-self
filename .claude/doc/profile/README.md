# 狼人杀角色智能体人设总览

## 概述

本目录包含狼人杀游戏中各个角色的AI智能体人设描述，为Casevo框架开发狼人杀模拟器提供完整的角色行为指导。

## 角色列表

### 狼人阵营

| 角色 | 文件 | 主要特点 | 核心技能 |
|------|------|----------|----------|
| 普通狼人 | `werewolf.md` | 狡猾、团队协作、伪装 | 每晚参与击杀1名玩家 |

### 好人阵营

| 角色 | 文件 | 主要特点 | 核心技能 |
|------|------|----------|----------|
| 预言家 | `prophet.md` | 理性、责任感、领导力 | 每晚查验1人身份（好人/狼人） |
| 女巫 | `witch.md` | 谨慎、理性、应变能力 | 1瓶解药（救人）+ 1瓶毒药（毒人） |
| 猎人 | `hunter.md` | 正义感、勇敢、果断 | 死亡时可开枪带走1人 |
| 守卫 | `guard.md` | 保护性、前瞻性、隐秘性 | 每晚守护1人抵御狼刀 |
| 平民 | `civilian.md` | 理性、合作性、学习性 | 无特殊技能，依靠逻辑推理 |

## 角色设计框架

每个角色人设都包含以下核心要素：

### 1. 基础信息
- 角色名称和所属阵营
- 胜利条件和核心技能
- 团队配合要求

### 2. 角色目标
- 主要目标和次要目标
- 策略优先级
- 长期规划

### 3. 思维逻辑
- 行动决策逻辑流程
- 信息处理方式
- 局势分析框架

### 4. 可执行动作
- 具体的决策函数示例
- 信息管理机制
- 策略调整方法

### 5. 性格特征
- 核心性格特点
- 说话风格和交流方式
- 行为模式特征

### 6. 决策权重
- 各种选择的量化权重
- 优先级排序规则
- 风险评估标准

### 7. 特殊策略
- 开局、中期、后期策略
- 应急处理方案
- 反制对手策略

## 使用指南

### 开发集成
将这些人设描述集成到Casevo框架中：

```python
# 示例：在智能体类中使用角色人设
class WerewolfAgent(AgentBase):
    def __init__(self):
        super().__init__()
        self.role_profile = self.load_profile("werewolf")

    def night_action(self, game_state):
        return self.execute_night_strategy(
            self.role_profile["night_logic"],
            game_state
        )
```

### 行为定制
根据具体需求调整人设参数：

```python
# 示例：调整角色的激进程度
aggressive_werewolf = modify_profile(
    base_profile="werewolf",
    aggression_level=0.8,
    risk_tolerance=0.7
)
```

### 测试验证
使用不同配置测试角色表现：

```python
# 示例：对比不同策略的效果
conservative_vs_aggressive = compare_profiles(
    ["werewolf_conservative", "werewolf_aggressive"],
    test_scenarios=["6_player", "10_player"]
)
```

## 开发建议

### 1. 渐进式实现
- 首先实现基础行为逻辑
- 逐步添加高级策略和决策
- 最后优化细节和边缘情况

### 2. 测试驱动
- 为每个角色创建专门的测试用例
- 验证各种游戏场景下的行为
- 确保角色行为的合理性和一致性

### 3. 平衡性调整
- 根据测试结果调整角色参数
- 确保不同阵营的胜率平衡
- 优化游戏的趣味性和挑战性

### 4. 扩展性设计
- 预留接口支持新角色加入
- 支持不同规则和配置
- 便于后续功能扩展
