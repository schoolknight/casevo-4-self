# 狼人杀人设JSON使用说明

## 概述

`person.json` 文件包含了狼人杀游戏中所有角色的标准化AI智能体人设数据，采用JSON数组格式，每个角色对象结构统一，便于程序直接读取和使用。

## 文件结构

### 基本信息
- **文件位置**: `.claude/doc/profile/person.json`
- **文件格式**: UTF-8编码的JSON数组
- **角色数量**: 6个完整角色（1个狼人 + 4个神职 + 1个平民）
- **数据大小**: 约400行，完整覆盖所有游戏角色

## JSON结构详解

### 标准角色对象结构

每个角色对象包含以下标准字段：

```json
{
  "id": "角色唯一标识符",
  "name": "角色中文名称",
  "name_en": "角色英文名称",
  "faction": "所属阵营",
  "victory_condition": "胜利条件描述",
  "skills": ["技能描述列表"],
  "objectives": {
    "primary": ["主要目标列表"],
    "secondary": ["次要目标列表"]
  },
  "personality": {
    "core": ["核心性格特点"],
    "speaking_style": ["说话风格特征"]
  },
  "abilities": ["能力列表"],
  "decision_weights": {
    "场景名称": {
      "选项描述": 权重值(0.0-1.0)
    }
  },
  "strategies": {
    "early_game": "开局策略描述",
    "mid_game": "中期策略描述",
    "late_game": "后期策略描述"
  }
}
```

### 字段详细说明

#### 基础信息字段
- **id**: 角色的唯一标识符，用于程序引用
- **name**: 角色的中文名称
- **name_en**: 角色的英文名称
- **faction**: 角色所属阵营（"狼人阵营" 或 "好人阵营"）
- **victory_condition**: 详细的胜利条件描述
- **skills**: 角色拥有的技能列表

#### 目标和性格字段
- **objectives**: 角色目标，分为主要目标和次要目标
- **personality**: 角色性格特征，包含核心性格和说话风格

#### 能力和策略字段
- **abilities**: 角色的具体能力列表
- **decision_weights**: 决策权重，用于概率计算（权重值0.0-1.0）
- **strategies**: 分阶段的游戏策略（开局、中期、后期）

## 数据访问方式

### 1. 基础数据读取
通过标准JSON解析库读取文件内容，获取角色列表数据。支持按角色ID、名称、阵营等维度进行查询。

### 2. 角色信息查询
- 根据ID获取特定角色的完整人设信息
- 根据阵营筛选角色（狼人阵营/好人阵营）
- 获取角色的技能、目标、性格等特定信息

### 3. 决策权重应用
每个角色的 `decision_weights` 字段包含了各种决策场景的权重分配，可用于：
- 概率性决策选择
- 行为倾向性控制
- 个性化AI表现

### 4. 策略阶段选择
根据游戏进度（天数、剩余玩家数等）选择对应阶段的策略：
- **early_game**: 游戏前期策略
- **mid_game**: 游戏中期策略
- **late_game**: 游戏后期策略
